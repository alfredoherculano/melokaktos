# Melokaktos <!-- Final name not decided -->
> Status: early development. Not yet functional.

## About
Melokaktos is a climbing log desktop application that allows users to record their climbs.

## Features
- Choose between two disciplines: sport climbing or bouldering.
- Set route name, grade, send type, date and crag location.

## Tech Stack
- Python, PySide6, SQLAlchemy, SQLite, Alembic
- Dependency management: uv

See [PLANNING](./docs/PLANNING.md) for project scope, architecture, and roadmap.
